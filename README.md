# Семейный retreat 2026

Страница: https://solilin.github.io/family-retreat-2026/

## Как опубликовать на GitHub Pages

1. Создайте на GitHub публичный репозиторий **family-retreat-2026** в аккаунте solilin.
2. Загрузите в корень репозитория всё содержимое этой папки (index.html, og.jpg, папку img, .nojekyll).
3. Settings → Pages → Build and deployment: Source «Deploy from a branch», Branch «main», папка «/ (root)». Save.
4. Через минуту-две страница откроется по адресу https://solilin.github.io/family-retreat-2026/

Если назовёте репозиторий иначе, замените адрес `https://solilin.github.io/family-retreat-2026/` в index.html (теги og:url, og:image, twitter:image) на новый.

Проверить превью ссылки: https://www.opengraph.xyz/ или отправить ссылку себе в Telegram.
